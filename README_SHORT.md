# Skyline Real Estate CRM

HTML5/CSS3/Vanilla JavaScript frontend, Spring Boot backend, MySQL database, and JWT authentication.

```powershell
cd backend-java
mvn spring-boot:run
```

```powershell
python -m http.server 3001 --directory frontend-html
```

Frontend: `http://localhost:3001`  
Backend: `http://localhost:8001/api/`
