# Pre-launch Checklist

- [ ] Java 17+ and Maven installed
- [ ] MySQL 8 is running on port `3306`
- [ ] MySQL credentials are set in `backend-java/src/main/resources/application.properties`
- [ ] `backend-java` builds successfully
- [ ] Spring Boot starts on port `8001`
- [ ] `http://localhost:8001/api/` returns the API health response
- [ ] HTML frontend starts on port `3001`
- [ ] Admin, Employee, and Agent login works
- [ ] CRUD and role restrictions are verified
